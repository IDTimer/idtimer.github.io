IDTimer Download

 

You can download ID Timer here. Click on the Windows/Linux icon and select the version of ID Timer that you wish to download. Place the downloaded .zip file on your desktop and "Extract" the folder and files.

The progran is "Portable" meaning that it doesn't require installation. You will find the file IDTimer in the "bin" folder. Double click on that to start the program. You can also create a shortcut or launcher to start the program.

Note: The Linux version of ID Timer does not currently run on Linux Mint Cinnamon 22.3, the Ubuntu version. It has been tested and runs perfectly on Linux Mint LMDE7. Other Distros have not been tested.
